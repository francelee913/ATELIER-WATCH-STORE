# ATELIER — Watch E-commerce Demo

A responsive React + Vite storefront for a fictional watch brand.

## Features
- Homepage, collection/shop, product detail, story, wishlist, cart, checkout, and confirmation pages
- Search, category filters, and sorting
- Add/remove/update cart quantities and dynamic totals
- Wishlist and cart persistence with localStorage
- Checkout form validation and simulated order confirmation
- Responsive CSS layouts, accessible labels, and lazy-loaded product images

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Notes
This is a front-end demo. Checkout does not process payments or create real orders. Product imagery is loaded from Unsplash and requires an internet connection.
